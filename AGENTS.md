# Nunna's AI Library — instructions for AI coding agents (same rules as CLAUDE.md)

- Source of truth = `library/*.json`. Everything in `dist/`, `INDEX.md`, `MINDMAP.md`, `MINDMAP.graphql`, `llms.txt`, `docs/apis/` is generated by `node scripts/build.mjs` — never hand-edit those.
- Add/update items with `node scripts/add.mjs <items.json> --source "<label>" --push` (or the MCP `add_items` tool). It dedupes, logs to CHANGELOG.md, rebuilds and pushes.
- **Always sync**: every change to the library must end with a commit + push to `origin main` (scnunna/Public-AI-Library).
- This repo is PUBLIC. Never add owner/company plans, emails, project refs, keys or infrastructure details. Private research lives in `private/` (gitignored) and is served only by the local `private_search` tool.
- Every curated item needs `verdict` (adopt|have|trial|assess|reference|skip) and a one-line `why`. Only set `verified: true` if you actually saw the page.
- Before researching a tool, call `why` — it may already have a verdict.
- Quick orientation: read `llms.txt` first, then `MINDMAP.graphql` (one runnable query per category) before opening the large JSON files.
- After changing `mcp/core.mjs` or `mcp/edge/index.ts`, redeploy the Supabase edge function `public-ai-library` (project xbinbulvanscbmfbvcio, verify_jwt=false) with files `index.ts` = mcp/edge/index.ts and `core.mjs` = mcp/core.mjs.
