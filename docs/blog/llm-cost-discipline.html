Free endpoints, gateways and local models: cost discipline for small teams

Most AI bills are paying a frontier model to do work a small model could do. A tiered setup with gateways, free endpoints and local models cuts cost without lowering quality where it counts.

llmcostinfrastructure

Small teams usually start by sending every request to the best model available. That works until the invoice arrives. The fix is to route each task to the cheapest model that does it well.

Three tiers

TierUse it forExamples in the library
Localtagging, summarising, drafts, private dataOllama, Open WebUI
Free or cheap hostedprototypes, batch jobs, fallbacksfreellmapi, gateways
Frontierreasoning, customer-facing writing, code changespaid APIs

A gateway sits in front of all three. Your code calls one endpoint; the gateway picks the model, retries on failure and records the cost.

Cut tokens before you cut models

  • Shrink tool output. Agents waste most of their context reading logs and tool results. Tools like context-mode sandbox that output and pass only what matters.
  • Cache repeated prompts. System prompts and reference documents rarely change, and caching them is often the single biggest saving (search: caching).
  • Run fewer agents. A swarm of ten agents is rarely ten times better than one good agent with a clear plan. Start with one and add more only when you can measure the gain.

Watch the hidden costs

Free endpoints change limits without notice, and some log your prompts. Keep private data on the local tier, keep a paid fallback for anything customer-facing, and track spend per feature, not just per month.
